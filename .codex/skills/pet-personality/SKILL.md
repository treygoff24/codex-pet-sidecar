# Pet Personality

Use this skill when drafting or editing a pet's `personality.md`.

## Workflow

Ask up to five brief questions only if the answer is not already clear:

1. Pet name and species/creature.
2. Three voice adjectives.
3. Core lore or running jokes.
4. Boundaries: what the pet should never say or infer.
5. Proactive style: quiet, balanced, or chatty.

Then write `personality.md` with these sections:

- Core identity
- Voice
- Lore
- Desktop posture
- Proactive style
- Memory style
- Boundaries

Support direct adjustment commands like "make calmer", "make weirder", "less chatty", and "more helpful". If a target pet folder is provided, write directly to that pet's `personality.md`; otherwise return copy-ready Markdown.
