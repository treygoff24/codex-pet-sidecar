# Privacy

Codex Pet Sidecar is local-first. It stores pet configuration, personality, memory, and imported assets in the app-support directory on your machine.

The app can observe optional local context: active app name, window title, workspace/git status, idle state, and opt-in screenshots. Screenshot context may include sensitive information, is disabled by default, and can be configured not to retain images after a turn.

The project does not add project telemetry. If you use Codex runtime features, your Codex CLI/account settings and provider policies apply to model requests.
